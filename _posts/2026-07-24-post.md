列表实现方式，使用 _posts 目录。
```html
<ul>
  {% for post in site.posts %}
    <li>
      {{ post.date | date: "%Y-%m-%d" }} - <a href="{{ post.url }}">{{ post.title }}</a>
    </li>
  {% endfor %}
</ul>
```

每个页面的头部需要带一个表
```md
---
date: 2026-07-24
title: "今天学会了 GitHub Pages 自动化"
---
```
